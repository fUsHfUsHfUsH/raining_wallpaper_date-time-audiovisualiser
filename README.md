# Rainy Window
<img src="preview.gif" width="300" />

Animated Rainy Window wallpaper for [Lively Wallpaper](https://github.com/rocksdanister/lively)

[Download](https://github.com/rocksdanister/rain/releases)

[Live Demo](https://www.rocksdanister.com/rain)

#### Features
- Custom image or video background.
- Rain particle intensity, speed, size control and lightning toggle (with storm-cloud darkening.)
- Background color temperature (post processing.)
- Background panning animation.
- Background mouse parallax.
- Background blur.
- Framerate control.
- Date/time overlay (12/24h, seconds, position, size, color, opacity.)
- Now Playing display: song title and artist under the visualizer (Lively system media), showing "Waiting for media" with an idle sweep animation when nothing is playing.
- Audio visualizer (Lively system audio or microphone) with amplitude, dot size, depth, high-frequency balance, color/rainbow and spectrum mode.
